# Aurelia's X queue

A curated list of X posts for Aurelia to reply to, like, or repost, served as a static page from `docs/`.

- `links.txt` — one post link per line, optional ` -- note` after it.
- `python3 build.py` — fetches the posts, writes `docs/index.html` (the site) and `dashboard.html` (a fragment for the claude.ai artifact).
- Push to `main` and GitHub Pages serves `docs/`.
